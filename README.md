# سپن (Sepan) — پیام‌رسان خصوصی و رمزنگاری‌شده


> نام قبلی این برنامه PChat بود. نام بسته (package) همان `com.pchat.app` مانده تا نسخهٔ جدید روی نسخهٔ قبلی نصب شود و پیام‌ها و کلیدها حفظ شوند.
**نسخه ۱.۰.۰**

پیام‌رسانی خصوصی برای گروه‌های کوچک (۱۰ تا ۲۰ گوشی اندروید) که روی **اینترنت ملی ایران** و بدون هیچ VPN یا شبکه‌ی خصوصی روی گوشی‌ها کار می‌کند. سرور آن روی یک VPS ایرانیِ شخصی اجرا می‌شود و هیچ وابستگی به سرویس‌های خارجی (مثل Firebase/Google Push) ندارد.

## چرا ساخته شد
- نیاز به پیام‌رسانی که با قطع اینترنت بین‌الملل هم کار کند
- رمزنگاری سرتاسری: سرور فقط داده‌ی رمزشده می‌بیند
- گوشی‌ها همیشه VPN فیلترشکن روشن دارند؛ پس برنامه نباید به VPN یا شبکه‌ی خصوصی دیگری نیاز داشته باشد
- کنترل کامل مدیر روی اینکه چه کسی چه کسی را می‌بیند

## امکانات
**گفتگو**
- چت خصوصی و گروهی، پاسخ به پیام، پین پیام، جستجو در گفتگو، دکمه‌ی پرش به آخرین پیام، کپی متن
- نشانگر «در حال نوشتن» و آنلاین/آفلاین
- صف ارسال: پیام‌های ارسال‌نشده با 🕓 می‌مانند و پس از وصل شدن شبکه خودکار دوباره فرستاده می‌شوند
- اعلان پیام و اتصال همیشه روشن در پس‌زمینه

**فایل و عکس**
- ارسال تا ۲ گیگابایت، تکه‌تکه (هر تکه ۱ مگابایت) و رمزشده
- ادامه‌ی خودکار آپلود و دانلود بعد از قطع شدن اتصال
- عکس‌ها بدون فشرده‌سازی و با کیفیت اصلی ارسال می‌شوند

**تماس**
- تماس صوتی و تصویری یک‌به‌یک با WebRTC و سرور TURN (coturn)، سیگنالینگ رمزشده

**هویت و دسترسی**
- نام نمایشی و عکس پروفایل (روی گوشی برش و کوچک و به WebP تبدیل می‌شود؛ اطلاعات EXIF/GPS حذف می‌شود)
- دسته‌بندی کاربران، گروه خودکار برای هر دسته
- ماتریس دید: مدیر تعیین می‌کند هر کاربر چه کسانی را ببیند و با چه کسانی بتواند گفتگو را شروع کند؛ پاسخ دادن به کسی که اول پیام داده همیشه ممکن است

**پنل وب مدیریت**
- مدیریت کاربران، دسته‌ها و ماتریس دید
- پایش زنده‌ی سرور: پردازنده، حافظه، دیسک، شبکه
- پشتیبان‌گیری زمان‌بندی‌شده (cron) از پایگاه داده، پشتیبان فوری و دانلود فایل فشرده

## ساختار مخزن
| مسیر | محتوا |
|---|---|
| `android/` | اپ اندروید (Kotlin، Jetpack Compose، فارسی و راست‌به‌چپ) |
| `server/src/` | کد سرور Node.js (API، پنل مدیریت، پشتیبان‌گیری، ابزار `msgadmin`) |
| `server/install.sh` | نصب و ارتقای سرور: کپی کد، سرویس systemd، گواهی، coturn برای تماس و پنل مدیریت |
| `docs/TUTORIAL.md` | آموزش کامل نصب و استفاده |
| `docs/ARCHITECTURE.md` | جزئیات فنی، رمزنگاری و API |
| `CHANGELOG.md` | تاریخچه‌ی نسخه‌ها |

## شروع سریع
۱. سرور (Ubuntu) را با اسکریپت‌های پوشه‌ی `server/` نصب کنید.
۲. کاربران را با `msgadmin add` بسازید.
۳. اپ را با Android Studio بسازید و روی گوشی‌ها نصب کنید.

راهنمای قدم‌به‌قدم در [docs/TUTORIAL.md](docs/TUTORIAL.md) است.

## تست‌ها
تست‌ها با `node:test` و بدون هیچ وابستگی npm نوشته شده‌اند (Node.js 22 یا جدیدتر):
```
npm test
```
- `test/crypto.test.js`: مسیر رمزنگاری ECDH روی P-256، سپس HKDF و AES-256-GCM و رمزنگاری تکه‌ای فایل (نسخه‌ی Node از `Crypto.kt` در `test/helpers/pchat-crypto.js`)
- `test/permissions.test.js`: ماتریس دید، پاسخ به کسی که اول پیام داده، گروه‌ها و کاربر غیرفعال
- `test/uploads.test.js`: آپلود تکه‌ای و ادامه‌ی آن پس از قطع اتصال، دانلود با Range و سهمیه‌ی فضا

تست‌ها همان کد سروری را اجرا می‌کنند که نصب می‌شود (`server/src/`). GitHub Actions این تست‌ها را روی هر PR اجرا می‌کند (`.github/workflows/ci.yml`) و ساخت اپ اندروید جداگانه در `.github/workflows/android.yml` انجام می‌شود.

## مخزن خصوصی
این مخزن خصوصی است. کلید خصوصی یا رمزی داخل آن نیست؛ تنها گواهی عمومی سرور برای pin کردن در اپ قرار دارد.
