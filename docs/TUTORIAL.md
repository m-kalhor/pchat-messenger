# آموزش نصب و استفاده

## پیش‌نیازها
- یک VPS لینوکسی در ایران (Ubuntu، حداقل ۱ هسته و ۱ گیگ RAM؛ برای فایل‌های بزرگ دیسک بیشتر بگیرید) با IP عمومی
- دسترسی root (مثلاً با Bitvise SSH Client)
- Android Studio برای ساخت اپ

## بخش ۱ — نصب سرور
کل پوشه‌ی `server/` (شامل `install.sh` و پوشه‌ی `src/`) را روی سرور کپی کنید (مثلاً با SFTP در Bitvise) و اسکریپت نصب را اجرا کنید. `YOUR_IP` همان IP عمومی سرور است.

```bash
cd server
bash install.sh YOUR_IP          # سرور + گواهی + coturn برای تماس + پنل مدیریت
```

نکات:
- `install.sh` یک گواهی ۱۰ ساله می‌سازد و در انتها نمایش می‌دهد. محتوای آن باید در `android/app/src/main/res/raw/server_cert.pem` باشد.
- برای ارتقا همان دستور را دوباره اجرا کنید. گواهی، کلید TURN و پایگاه داده حفظ می‌شوند و قبل از ارتقا یک نسخه‌ی پشتیبان از برنامه و پایگاه داده در `/root/messenger-backup-...` گذاشته می‌شود.
- ورود به پنل مدیریت با نام کاربری و رمز است. نام کاربری پیش‌فرض `admin` است و رمز فقط یک بار نمایش داده می‌شود. هر دو را می‌توانید در تب «حساب مدیر» پنل عوض کنید. اگر رمز گم شد: `msgadmin adminpw`.

حالت‌های دسترسی پنل مدیریت (آرگومان دوم `install.sh`):
| دستور | معنی |
|---|---|
| `bash install.sh YOUR_IP` | پنل از کل اینترنت باز است (پورت ۸۴۴۴، با محدودیت تلاش) |
| `bash install.sh YOUR_IP ADMIN_IP` | فقط از همان IP |
| `bash install.sh YOUR_IP local` | فقط از خود سرور (با تونل SSH) |

برای امنیت بیشتر پیشنهاد می‌شود پنل فقط روی IP خودتان باز باشد و رمز طولانی انتخاب کنید.

### بررسی سلامت
```bash
systemctl is-active messenger coturn fail2ban
curl -sk https://127.0.0.1:8443/api/health      # باید {"ok":true} بدهد
journalctl -u messenger -n 50 --no-pager
free -m ; df -h /
```

## بخش ۲ — مدیریت کاربران
از خط فرمان سرور:
```bash
msgadmin add USERNAME     # ساخت کاربر (رمز نمایش داده می‌شود)
msgadmin reset USERNAME   # رمز جدید
msgadmin del USERNAME     # حذف
msgadmin list             # فهرست
msgadmin adminpw          # رمز جدید پنل مدیریت
msgadmin adminuser NAME   # تغییر نام کاربری پنل مدیریت
```
نام کاربری فقط حروف کوچک انگلیسی، عدد و زیرخط (۲ تا ۲۰ نویسه) است.

## بخش ۳ — پنل مدیریت
آدرس: `https://IP-سرور:8444` (مرورگر به‌خاطر گواهی خودامضا هشدار می‌دهد؛ ادامه دهید).

- **کاربران:** ساخت، غیرفعال‌کردن، بازنشانی رمز، تعیین نام نمایشی، عضویت در دسته‌ها
- **دسته‌ها:** هر دسته یک گروه گفتگو می‌سازد. فقط اعضای دسته آن گروه را می‌بینند. (دسته‌ی شماره‌ی ۱ «عمومی» است.)
- **ارتباط کاربران:** کاربر را از فهرست انتخاب کنید و برای هر نفر دیگر «وصل»، «بدون ارتباط» یا «⛔ بسته» بزنید. ارتباط دوطرفه است: دو کاربر وصل هر دو می‌توانند گفتگو را شروع کنند. به کسی که اول پیام داده همیشه می‌شود پاسخ داد (مگر بسته باشد). دکمه‌های «وصل به همه»، «وصل به اعضای دسته» و «کپی ارتباط‌های کاربر دیگر» برای تعداد زیاد کاربر است.
- **موبایل:** در تب کاربران برای هر کاربر شمارهٔ موبایل ثبت کنید (برای ورود با پیامک در نسخه‌های بعد).
- **پایش:** نمودارهای زنده‌ی CPU، RAM، دیسک و ترافیک شبکه
- **پشتیبان‌گیری:** زمان‌بندی با عبارت cron، تعداد نگهداری، «پشتیبان فوری» و دانلود فایل فشرده

## بخش ۴ — ساخت و نصب اپ اندروید
پوشه‌ی `android/` یک پروژه‌ی کامل Gradle است و مستقیم ساخته می‌شود.

1. آدرس سرور را در `android/gradle.properties` تنظیم کنید (یا بدون تغییر فایل، در `android/local.properties` بنویسید):
   ```properties
   pchat.serverHost=IP-سرور-شما
   pchat.serverPort=8443
   ```
   یا موقع ساخت: `./gradlew assembleRelease -Ppchat.serverHost=1.2.3.4`
2. مطمئن شوید `android/app/src/main/res/raw/server_cert.pem` گواهی همان سرور است.
3. پوشه‌ی `android/` را در Android Studio باز کنید (File ← Open) و Run بزنید؛ یا در خط فرمان:
   ```bash
   cd android
   ./gradlew assembleRelease
   ```
   فایل APK در `android/app/build/outputs/apk/release/app-release.apk` ساخته می‌شود.

پیش‌نیاز: JDK 17 و Android SDK (Android Studio هر دو را دارد). هر تغییر در `android/` روی GitHub Actions هم ساخته می‌شود و APK آن در بخش Artifacts همان اجرا قابل دانلود است.

## بخش ۵ — نسخهٔ وب برای آیفون
`install.sh` نسخهٔ وب را هم نصب می‌کند: پورت ۴۴۳ برای خود برنامه و پورت ۸۰ فقط برای صفحهٔ راهنما و دریافت گواهی. هر دو پورت در فایروال باز می‌شوند.

**گواهی رایگان بدون دامنه:** Safari گواهی خودامضای پورت ۸۴۴۳ را قبول نمی‌کند. برای همین `install.sh` یک «گواهی ریشهٔ سپن» (Sepan Root CA) می‌سازد. کلید خصوصی آن فقط در اختیار root است (`/opt/messenger/ca/`). با آن، یک گواهی ۸۰۰ روزه برای IP سرور در `/opt/messenger/certs/web/` صادر می‌شود. اسکریپت `/usr/local/sbin/sepan-web-cert` هر شب از cron اجرا می‌شود و ۳۰ روز مانده به انقضا گواهی را تمدید می‌کند. سرور هر یک ساعت گواهی را دوباره می‌خواند و به راه‌اندازی مجدد نیازی نیست. اثر انگشت گواهی ریشه در پایان `install.sh` نمایش داده می‌شود؛ آن را به کاربران بدهید تا با صفحهٔ نصب مقایسه کنند.

**نصب روی هر آیفون (یک بار):**
1. در Safari آدرس `http://IP-سرور/setup` را باز کنید و «دریافت گواهی سپن» را بزنید (Allow).
2. Settings ← Profile Downloaded ← Install.
3. Settings ← General ← About ← Certificate Trust Settings ← روشن کردن Sepan Root CA.
4. `https://IP-سرور/` را باز کنید، وارد شوید و از دکمهٔ اشتراک‌گذاری «Add to Home Screen» را بزنید.

**نکته‌ها:**
- کلید رمزنگاری با پشتیبان رمزشده (با رمز حساب) روی سرور نگه داشته می‌شود. ورود دوباره یا ورود از آیفون تازه همان کلید را برمی‌گرداند و پیام‌های قبلی (تا ۹۰ روز) خوانا می‌مانند. یک حساب را می‌شود هم‌زمان روی اندروید و آیفون استفاده کرد.
- آیفون اجازهٔ اتصال دائم در پس‌زمینه را به وب‌اپ نمی‌دهد. پیام و تماس فقط وقتی سپن باز است می‌رسد؛ بعد از باز کردن، پیام‌های جامانده خودکار می‌آیند.
- حداکثر حجم فایل در نسخهٔ وب ۲۰۰ مگابایت است (مرورگر فایل را در حافظه نگه می‌دارد).
- **رفتن به دامنه در آینده:** گواهی دامنه (مثلاً Let's Encrypt) را با همان نام‌های `cert.pem` و `key.pem` در `/opt/messenger/certs/web/` بگذارید. اسکریپت تمدید، گواهی صادرشده از مرجع دیگر را دست نمی‌زند. چون آدرس عوض می‌شود، کاربران آیفون باید آیکون را دوباره به صفحهٔ اصلی اضافه کنند و یک بار وارد شوند. کلید از پشتیبان سرور برمی‌گردد و تاریخچه حفظ می‌شود.

## بخش ۶ — استفاده از اپ
- **ورود:** نام کاربری و رمزی که مدیر داده را وارد کنید.
- **پروفایل:** منوی ⋮ ← «پروفایل من»؛ نام نمایشی و عکس.
- **ارسال فایل/عکس:** دکمه‌ی «+» کنار کادر پیام. عکس‌ها بدون فشرده‌سازی می‌روند. اگر شبکه قطع شود، ارسال خودکار ادامه پیدا می‌کند.
- **پین:** نگه داشتن انگشت روی پیام ← «پین کردن». برای رفتن به پیام پین‌شده، نوار بالای گفتگو را بزنید.
- **جستجو:** 🔍 بالای گفتگو. **پرش به آخر:** دکمه‌ی ⬇.
- **تماس:** آیکن تلفن یا دوربین بالای گفتگوی خصوصی.
- **امنیت:** آیکن 🔒 اثرانگشت کلیدها را نشان می‌دهد؛ برای اطمینان کامل آن را حضوری با طرف مقابل مقایسه کنید.
- در گوشی‌های شیائومی/سامسونگ/اوپو، «شروع خودکار» و «بدون محدودیت باتری» را برای برنامه فعال کنید تا اتصال پس‌زمینه قطع نشود.

## رفع اشکال
| مشکل | راه‌حل |
|---|---|
| اپ وصل نمی‌شود | `systemctl status messenger` و `ufw status` را روی سرور بررسی کنید؛ پورت ۸۴۴۳ باید باز باشد |
| بعد از عوض‌کردن گواهی خطای SSL | گواهی جدید را در `server_cert.pem` بگذارید و اپ را دوباره بسازید |
| تماس صدا ندارد یا وصل نمی‌شود | پورت‌های ۳۴۷۸ (tcp/udp) و ۴۹۱۵۲–۴۹۳۵۲ (udp) باز باشند و `systemctl status coturn` فعال باشد |
| آیفون می‌گوید اتصال امن نیست | مرحلهٔ «Certificate Trust Settings» انجام نشده، یا گواهی وب برای IP دیگری صادر شده: `sepan-web-cert` را اجرا کنید |
| نسخهٔ وب باز نمی‌شود | `ufw status` باید پورت‌های ۴۴۳ و ۸۰ را باز نشان دهد و هیچ برنامهٔ دیگری (مثل nginx) روی آن‌ها نباشد؛ `journalctl -u messenger` را ببینید |
| پیام «قابل رمزگشایی نیست» | احتمالاً کلید قدیمی است (گوشی یا برنامه عوض شده)؛ هشدار تغییر کلید را بررسی کنید |
| ورود SSH ناموفق می‌شود | fail2ban ممکن است IP را موقتاً مسدود کرده باشد؛ چند دقیقه صبر کنید |
| پر شدن دیسک | دیسک VPS را افزایش دهید؛ سقف فضای فایل‌ها با متغیرهای `MAX_TOTAL_MB` و `MIN_FREE_MB` تنظیم می‌شود |
